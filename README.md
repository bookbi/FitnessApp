# FitnessApp


โปรเจคนี้เป็นระบบจำลองการจองคลาสออกกำลังกายในฟิตเนส โดยเน้นการออกแบบเชิงวัตถุ 

(Object-Oriented Programming ) เพื่อให้ผู้ใช้งานสามารถ 

-สมัครสมาชิกได้ทั้งแบบปกติและแบบพรีเมียม

-ดูรายชื่อคลาสออกกำลังกาย

-จองคลาสออกกำลังกายผ่านระบบได้

🔧 ฟีเจอร์ที่ระบบสามารถทำได้

1) สมัครสมาชิก

ผู้ใช้สามารถกรอกชื่อ และเลือกได้ว่าจะเป็นสมาชิกพรีเมียมหรือไม่
แล้วระบบจะสุ่มรหัสสมาชิกให้

2) ดูข้อมูลส่วนตัว

แสดงชื่อ รหัสสมาชิก และสิทธิพิเศษ(ถ้าเป็นพรีเมียม)

3) ดูรายชื่อคลาสที่เปิดสอน

เช่น Yoga, HIIT, Pilates พร้อมชื่อผู้สอนและจำนวนคนที่จองแล้ว

4) จองคลาสออกกำลังกาย

ระบบเช็คจำนวนที่นั่งว่าง และอัปเดตสถานะการจอง

5) ออกจากระบบ
